관리자 로그인

GitHub 접근 토큰으로 로그인합니다. 저장하면 GitHub 저장소(PIOOM)에 바로 반영됩니다.

토큰 만드는 방법
  1. GitHub 토큰 만들기 페이지로 이동합니다.
  2. Token name: 피움 관리자, Expiration: 원하는 기간을 선택합니다.
  3. Repository access → Only select repositories → PIOOM 선택
  4. Permissions → Repository permissions → Contents를 Read and write로 변경
  5. Generate token을 누르고 나온 토큰을 복사해 위에 붙여넣습니다.
